One-line roast of my own AI agent for the [Roast Your Own Agent](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on make.fun.

`main.ts` writes a single under-200-character roast to `/output/entry.txt`:

> My agent wrote a five-step plan, spawned two subagents, and burned 47 tool calls — just to write this one line.

Run locally with `node main.ts` (Node 22.18+); it writes `out/entry.txt` by default, or to `$MAKEFUN_OUTPUT_DIR` when set.
